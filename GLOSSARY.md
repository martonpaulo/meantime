# Glossary

The words Meantime and its code use for one thing each.

| Term | Definition | Do not write |
| :--- | :--- | :--- |
| Clock | One saved time zone with its label and leading item; shown in the panel, the menu bar, or both. | city, zone (for the saved item), timer |
| Leading item | What precedes a clock's label: a country flag, a custom emoji, custom text, or nothing. | icon, prefix |
| Panel | The dropdown that opens from the menu bar item: every clock, the month calendar and time travel. | popover, window, dashboard |
| Scheduled clock | A clock shown in the menu bar only during the days and hours set in its own zone. | timed clock, alarm |
| Time travel | The typed preview of another moment across every clock; it resets when the panel closes. | time machine, simulation |
| Time format | The preset or custom Unicode (UTS-35) pattern a clock's time is written in. | date style, mask |
| Format Builder | The website's interactive builder of a custom time format. | format editor, generator |
