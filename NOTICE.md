# Attributions

Meantime is built with Apple's SwiftUI, AppKit, and Foundation, and bundles the
following third-party component in release builds.

## Sparkle

- Project: https://github.com/sparkle-project/Sparkle
- Purpose: automatic updates for the direct-download build.
- License: MIT (with additional permissive licenses for bundled components; see
  the Sparkle repository's `LICENSE`).

The time-zone → region table used for flag emoji is generated from the IANA time
zone database shipped with macOS (`/usr/share/zoneinfo`), which is in the public
domain.
